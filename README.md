# rain-cloud-scraper-predictor
Yet another web scraper project, currently using NEA's rain data. Hopefully I don't get IP banned again.

## Folder structure description

### `scraper/`
The web scraper for the images. Running 24/7 with variable timing to avoid IP bans

### `png_to_usable_data/`
Folder to convert .png files to usable training data.

png decoder module is from my other repository [png-decoder](https://github.com/BlazeChron/png-decoder)
